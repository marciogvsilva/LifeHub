# Estudo — Anotações gerais

Anotações que **não pertencem a um card específico**: conceitos que apareceram de passagem, dúvidas soltas, leituras, comandos úteis e ideias para o futuro.

> Quando uma anotação daqui virar assunto de um card, mova-a (ou crie um link) para o `CARD-NNN.md` correspondente.

## Como usar

- Cada anotação é uma entrada com **data**, **título** e **tags**, na seção do tema.
- Não precisa estar bonita: o objetivo é não perder a ideia. Refine depois.
- Use os mesmos marcadores dos estudos dos cards: 💡 para insights, ⚠️ para armadilhas e ❓ para dúvidas em aberto.

### Modelo de entrada

```markdown
### AAAA-MM-DD — Título curto
**Tags:** java, spring, sql...
**Contexto:** onde isso apareceu (um erro, uma leitura, uma conversa).

O que aprendi, com as minhas palavras.

- **Exemplo:** um trecho de código ou comando, se ajudar.
- **Fonte:** link, livro ou capítulo.
- **Relacionado:** [CARD-NNN](CARD-NNN.md), outro tema desta página.
```
